## 4. 키워드·태그 생성 파이프라인 (채널 무관)

1. AI가 상품별 상품명 후보·태그 초안 생성 (카테고리·브랜드·모델·소재·성별 구조화 입력)
2. **검색량 검증(자동)** — 검색광고 API 키워드도구(`/keywordstool`)로 월간 검색수·경쟁도 전 건 조회, 검색량 0 키워드 폐기. AI 단독 생성 금지. 상품별 **타깃 키워드 1~3개** 지정·기록 — 제작계획 §6 순위 추적의 입력
3. 규칙 자동 검사기 — 글자 수·언어(일본어 잔존)·키워드 중복·금지 문구·특수문자 전 건 검사
4. 표본 수동 검수 — EP 연동 후 네이버쇼핑 실노출 표본 확인으로 수행(구 스마트스토어 검색품질 체크는 소멸)

현재 검색광고 API 키 미확보(제작계획 ST0 ⑦)로 2단계가 차단 상태 — 키워드 태그는 검증 전 확정 등록하지 않는다(§8 잔여 ②).

## 9. 카테고리 체계 (설계 문서 흡수 — 2026-08-18)

별도 문서(`카페24자사몰_카테고리설계_v1_0~v3_0`)로 관리하던 체계 설계를 본 문서로 흡수하고 원 문서는 폐기했다(2026-08-18). 카테고리는 상품 데이터의 배정 축이므로 전처리 SoT가 함께 관장한다.

**확정 근거**: 2026-08-18 중간점검 대표 확정 — **1차 분류 = 브랜드**(구매대행·중고명품 공통, 로고 병기), 품목 기반 1차 필터 폐기. 구 설계의 품목 중심 트리(가방 > 숄더백·토트백 …)는 실사용 가치 없음으로 폐기 판정([회의록](../history/meeting/2026-08-18_회의록_카페24자사몰_중간점검_cafe24_mall_midpoint_review_meeting_minutes_v1_0.md) §1·§2).

### 9.1 설계 원칙

1. **최상위 = 거래 체계 축 유지.** `구매대행`(62) / `중고명품`(63) — 배송·재고 체계가 다르다. 페이지 이원화(설계 레벨 전환)는 미채택, 상단 버튼 시각 구분 + 중고명품 전용 배너로 대체(회의 §2).
2. **2단 = 브랜드.** 중고명품도 동일 규칙(하위 생성은 대표 재고 정리 후).
3. **3단 = 품목 6분류**(가방·지갑·소품·신발·의류·모자·액세서리) — 브랜드가 실제 보유한 품목만 생성하고, **품목이 1종뿐인 브랜드는 3단을 만들지 않는다**(상품을 브랜드 노드에 직배치).
4. **구 세부 34분류(숄더백·토트백·부츠 …)는 생성하지 않는다** — 브랜드×품목×세부로 쪼개면 명품 풀 1,326건의 말단 대부분이 한 자릿수가 된다.
5. **헤더 메뉴는 최상위 2개뿐.** `use_main=T`는 구매대행·중고명품에만 주고 **브랜드·품목 노드는 전부 `use_main=F`** — 브랜드는 각 최상위 안의 하위 필터로 렌더된다(구 품목 대분류가 있던 자리를 그대로 대체). 구매대행에는 구매대행 브랜드 필터가, 중고명품에는 중고명품 브랜드 필터가 각각 붙는다.
6. **브랜드 필드(Collection API, `B000000A~`)는 유지**(상품 속성·검색·기획전용), **브랜드기획전 분류(105~107)는 폐기** — 브랜드가 정규 트리 축이 되어 중복이다.
7. 이관 범위·제외 규칙: **명품 단독**(§1), 바이마 4472(추가 결제용 출품) 제외, depth1=`기타` 품목은 트리 미생성 → 등록 차단(프라다 2건 해당).

### 9.3 배정·노출 규칙

- **상품 배정**: `category_no = f(브랜드, depth1)` — 품목 노드가 있으면 품목 노드, 없으면 브랜드 노드. 상품당 분류 1개(§1) 유지, 교차 노출은 기획전·메인진열 담당.
- 브랜드 정렬은 물량 순. 분류 `display_order`는 PUT이 무시되므로 순서는 관리자 화면 수동 조정([`AdminAPI 실스펙 v1.0`](카페24자사몰_AdminAPI실스펙_cafe24_admin_api_spec_v1_0.md) §8).
- 헤더 메뉴는 스킨 `Layout_category`가 `use_main=T` 분류만 렌더 — **최상위 2개에만 부여**한다. 브랜드에 T를 주면 구매대행과 나란히 헤더로 올라가 대체 관계가 깨진다(2026-08-18 실행 중 발생·정정). 템플릿 `<li>` 개수는 노출 개수를 제한하지 않는다 — 모듈이 레코드 수만큼 자동 반복한다(PC 3칸·모바일 2칸 템플릿에 4개 렌더 실측).
- **스킨 브랜드 필터**: 하드코딩 블록(브랜드기획전 `cate_no=105~107`, 커밋 `d0e56cd`)을 **제거 완료**(2026-08-18, 커밋 `a1abe54`) — 브랜드가 정규 분류가 되면서 `product_displaycategory` 하위분류 탭이 현재 최상위의 브랜드를 그대로 렌더한다. 하드코딩을 남기면 중복이자, 중고명품 페이지에서 구매대행 브랜드를 노출하는 오작동이 된다. 브랜드 로고 병기는 ST6 시안(대표 컨펌 이월) 사항.
