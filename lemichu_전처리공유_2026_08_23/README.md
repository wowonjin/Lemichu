# lemichu 데이터 전처리 공유 패키지 (2026-08-23)

BUYMA 수출 데이터 → 카페24 자사몰 등록까지의 전처리 파이프라인 중간 결과물입니다.
테스트셋 30건(프라다·미우미우·셀린느)으로 전 구간 실증을 마친 상태이며, 각 폴더는 파이프라인 진행 순서대로 구성했습니다.

## 폴더 구성

### 1_브랜드선별표

`brand_selection.csv` — 출품중 4,539건·67개 브랜드 전수 판정표. Excel에서 바로 열립니다.

- **편입** 26브랜드 1,342건 — 이관 대상 (스포츠·캐주얼 제외 전 브랜드)
- **제외** 26브랜드 3,131건 — 스포츠·캐주얼
- **보류** 15브랜드 66건 — 뷰티·리빙·토이·브랜드 불명 등, **검수 요청 드리는 부분입니다.** 편입/제외 판단만 표시해 주시면 반영하겠습니다.

### 2_중간산출물_테스트셋30건

전처리 각 단계의 실제 산출물입니다. 순서대로 보시면 원본이 어떻게 바뀌는지 확인됩니다.

| 파일 | 단계 |
| --- | --- |
| `products.csv` · `color_size_options.csv` | ① BUYMA 원본에서 대상 30건 추출 |
| `product_names_rewritten.csv` | ② 상품명 일→한 재작성 (원문 대조 가능) |
| `staging_products.json` | ③ 전처리 완료본 — 등록 직전 최종 데이터 (가격 환산·카테고리 배정·옵션 정리 포함) |
| `validation_report.md` | ③의 자동 검증 리포트 |
| `verify_report.md` | ④ 등록 후 몰 실데이터와 전수 대조한 검증 리포트 (30/30 통과) |

### 3_설계문서

`카페24자사몰_데이터전처리_...md` — 전처리 원칙·필드 매핑·검증 게이트 전체를 담은 설계 문서.
가격 환산(100엔=920원, 판매가 만원 단위 내림), 상품명 재작성 규칙, 카테고리 체계가 모두 여기 정리되어 있습니다.

### 4_코드

파이프라인 실행 순서대로:

| 파일 | 역할 |
| --- | --- |
| `build_testset.py` | 원본에서 대상 상품 추출 |
| `preprocess_buyma_to_cafe24.py` | 전처리 본체 — 조인·환산·정규화 → 등록용 JSON |
| `check_product_names.py` | 재작성 상품명 규칙 검사 |
| `create_categories.py` | 브랜드별 카테고리 트리 생성 |
| `register_products.py` | 카페24 Admin API 상품 등록 |
| `verify_registration.py` | 등록 결과 전수 검증 |
| `cafe24_auth.py` | API 인증 모듈 (위 등록·검증 스크립트가 사용) |
| `buyma_category_map.csv` · `brand_map.csv` | 카테고리·브랜드 대응표 |

API 인증 키·토큰은 별도 설정 파일로 분리되어 있어 이 패키지에는 포함되지 않습니다.
